# 🎙️ DevVoice REBORN V2: Повна Документація

**DevVoice REBORN V2** — це екосистема для "вайб-кодингу", інтелектуальний "Другий Мозок" для розробників, що дозволяє миттєво перетворювати голос у структуровані технічні нотатки, ADR (Architecture Decision Records) та звіти про баги.

---

## 🏗️ Архітектура та Технологічний Стек

Система побудована за принципом **Local-First, Cloud-Synced**, що забезпечує максимальну швидкість роботи та доступність даних офлайн.

*   **Frontend**: React + TypeScript + Vite.
*   **Держава (State)**: Zustand (модульна архітектура зі слайсами).
*   **Локальна база**: IndexedDB (через бібліотеку Dexie).
*   **Хмарна інфраструктура**: Firebase (Auth, Firestore, Hosting).
*   **Синхронізація**: `UnifiedSyncService` (координатор між Local FS, Firebase та GDrive).
*   **Безпека**: Web Crypto API (AES-GCM 256).

---

## 🌟 Ключові Можливості

### 1. Голосовий Інтелект (Voice-to-JSON)
*   **Транскрибація**: Підтримка нативного Browser Speech API та високоточного **Groq Whisper** (Llama 3.3).
*   **Авто-категоризація**: AI автоматично визначає тип нотатки:
    *   💡 **Idea**: Архітектурні думки та пропозиції.
    *   🐞 **Bug**: Опис помилки з кроками для відтворення.
    *   🏗️ **Architecture**: ADR або системний дизайн.
    *   ✅ **Todo**: Завдання для виконання.
    *   📝 **Generic**: Загальні нотатки.
*   **Розумні теги**: Автоматичне вилучення ключових слів та контексту.

### 2. Гібридна Синхронізація (Universal Sync)
Система працює одночасно з трьома джерелами:
*   **Local File System**: Нотатки фізично зберігаються на вашому диску як `.md` файли (вимагає дозволу на доступ до папки).
*   **Firebase Cloud**: Миттєва синхронізація між пристроями через Firestore.
*   **Google Drive**: Створення ZIP-бекапів та зберігання в персональному сховищі користувача.
*   **Real-time Updates**: Використання Firestore Snapshots для миттєвої появи нотаток на всіх авторизованих пристроях.

### 3. Безпека "Параноїдального" Рівня
*   **Клієнтське шифрування (AES-256)**: Ваші дані шифруються безпосередньо у браузері перед відправкою у хмару.
*   **Майстер-пароль**: Тільки ви знаєте ключ дешифрування. Навіть адміністратори Firebase не можуть прочитати ваші нотатки.
*   **Local-Clear / Cloud-Encrypted**: На диску дані відкриті для зручного локального пошуку (grep/IDE), у хмарі — надійно захищені.

### 4. AI-Місток (Browser Bridge)
Унікальна технологія, що дозволяє використовувати топові моделі безкоштовно через ваші відкриті вкладки:
*   **Підтримка**: ChatGPT, Gemini, Claude, Grok.
*   **Persistent Ports**: Постійний зв'язок між додатком та вкладкою AI, що запобігає їх присиплянню.
*   **Auto-Wake**: Автоматичне "пробудження" вкладки AI на мить для відправки запиту та повернення в додаток.

## ⚙️ Налаштування та Використання

### Встановлення AI-містка (Extension)
1.  Зайдіть у **Settings > Security**.
2.  Натисніть **Download Extension Files (ZIP)**.
3.  Розпакуйте архів.
4.  Відкрийте `chrome://extensions`, увімкніть **Developer mode**.
5.  Натисніть **Load unpacked** та виберіть розпаковану папку.

### Налаштування шифрування
1.  У налаштуваннях встановіть **Master Password**.
2.  Додаток автоматично почне шифрувати всі нові та оновлені нотатки перед відправкою в Cloud.
3.  *Увага: Втрата пароля зробить хмарні дані нечитабельними при вході з нового пристрою.*
